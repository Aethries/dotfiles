# Feature 10: AI Assistant stack

The repository owns the AI workstation contract. `./scripts/ai.sh` is the
control plane; `./scripts/bootstrap.sh` invokes it after the NixOS rebuild.

## Runtime ownership

| Layer | Repository source | Runtime location |
| --- | --- | --- |
| Versions and checksums | `resources/ai/manifest.json`, `pkgs/` | Nix store |
| Client config | `resources/ai/shared/`, `resources/ai/clients/` | strict symlinks under client homes |
| OmniRoute credentials/database | service template | `~/.local/state/omniroute` |
| AI control state | scripts | `~/.local/state/dotfiles/ai` |
| CodeGraph graph/memory metadata | `scripts/ai.sh codegraph` | `~/.local/state/dotfiles/codegraph` and CodeGraph runtime state |
| Disposable cache | manifest contract | `~/.cache/dotfiles/ai` |

OmniRoute 3.8.50 is the only default client gateway:

```text
Codex / Gemini / Antigravity
             |
             v
http://127.0.0.1:20128/v1
             |
             v
         OmniRoute
```

The systemd service uses the verified upstream contract `PORT=20128` and
`OMNIROUTE_SERVER_HOST=127.0.0.1`. It does not enable user lingering.

RTK 0.48.0 is available as a pinned CLI for explicit terminal compression.
Caveman 2.7.0 is distributed as a shared repo-owned skill. It does not create
a global proxy. CodeGraph 0.20.1 is exposed through a small `core` MCP profile
and is restricted to a Git workspace.

Bifrost 2.2.0 is optional and disabled by default. When explicitly enabled,
the pinned Docker image listens on loopback port 8080 and OmniRoute uses its
documented `BIFROST_BASE_URL` / `BIFROST_ENABLED` boundary. No client points at
Bifrost directly.

## Safe operations

```bash
./scripts/ai.sh doctor
./scripts/ai.sh generate
./scripts/ai.sh sync
./scripts/ai.sh codegraph index .
./scripts/ai.sh codegraph status .
./scripts/ai.sh test
```

AI config sync refuses regular files and unrelated symlinks. `--adopt` is an
explicit action that creates a dated backup before linking the repo-owned file.
Provider keys and client credentials are never generated by this repository.
